# Prime Training 5.3 — Final Release

Versión construida sobre Prime Training 5.2 estable.

## Cambios

- Registro corporal simplificado: únicamente peso, altura y nota opcional.
- Porcentaje de grasa corporal estimado automáticamente y marcado como aproximado.
- Chequeo semanal obligatorio los lunes si todavía no existe un registro de esa semana.
- Evolución de peso con curva, historial, variación semanal y análisis según objetivo.
- Calorías y macronutrientes se recalculan con el último peso guardado y el objetivo actual.
- Nuevo panel semanal en Inicio con peso, tendencia, calorías y proteína.
- Mejoras de interfaz y adaptación mobile del registro y progreso.
- Chat, entrenamiento, reportes, Supabase y PrimeState permanecen sin cambios funcionales.

## Publicación

Subir todo el contenido manteniendo las carpetas. Reemplazar también `sw.js` para activar la caché `prime-training-v53-final`.

No requiere nuevas queries ni cambios en los secrets o la Edge Function.
